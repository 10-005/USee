# 산책 음성 명령 (S15P31D106-358)

- Android 산책 화면에서 강아지가 배치되면 마이크 권한을 요청하고 한국어 음성 인식을 시작한다.
- 호출어 등록 없이 이름 뒤에 붙인 `앉아`, `멈춰`, `가자`, `돌아`를 인식한다. 이름 없이 명령만 말해도 된다.
- 최종 인식 결과만 실행한다. 알 수 없는 발화에는 지원 키워드를 안내한다.
- `앉아`: SitStart 이후 SitIdle을 반복하며 위치를 유지한다. 사용자가 움직여도 따라가지 않는다.
- `멈춰`: 서 있는 Idle 자세로 위치를 유지한다. 사용자가 움직여도 따라가지 않는다.
- `가자`: 앉기/정지를 해제하고 이동을 재개한다. 앉기와 정지는 자동으로 해제되지 않는다.
- `돌아`: 현재 위치를 고정하고 TurnRight 모션과 함께 약 3초간 360도 한 바퀴 회전한다. 완료 후 서서 정지하며 `가자`로 이동을 재개한다. 회전 중 반복 요청은 무시하고, 다른 행동 명령이나 추적 중단은 회전을 취소한다.
- 이름 설정 화면에서 입력한 한글 1~6글자 이름을 모의 입양 세션에 저장한다. 이름 단독 또는 이름+야/아를 부르면 3초 동안 몸통을 멈추고 목·머리만 카메라를 보며 처음 2초간 꼬리를 흔든다. 이름과 행동 명령을 함께 말하면 행동 명령만 실행한다. 기존 세션에 이름이 없으면 이름 호출을 적용하지 않는다.
- 정지 중 목줄 호출·재배치·자동 배변은 위치를 변경하지 않는다. 추적 중단·복귀에도 정지 명령을 유지한다. 배변이 이미 진행 중이면 음성 동작 요청을 무시한다.
- 음성 스위치 끄기, 화면 이탈, 앱 백그라운드 전환 시 음성 인식을 해제한다.
- 온디바이스 인식을 우선 사용하고 한국어 모델이 없으면 일반 인식 서비스로 전환한다. 일반 서비스는 기기에 따라 네트워크와 음성 전송을 사용할 수 있다.
- 결과/무응답 후 새 인식 세션을 시작하므로 세션 사이에는 짧은 공백이 있다. 서비스 오류는 간격을 두고 재시도하고 3회 연속 실패하면 중단한다. 스위치를 껐다 켜면 재시도한다.

## 실기기 확인

배변봉투는 좌측 하단에 항상 표시한다. 재고가 없으면 어둡게 표시하고, 누르면 배변봉투 한 묶음(현재 10장·500원)만 구매하는 다이얼로그를 연다. 가격·수량은 상점 상품 데이터를 따른다. 남은 예산이 충분할 때 구매액·보유 목록·재고를 같은 저장 데이터에 반영하며, 기존 장바구니는 유지한다. 구매 후 2m 이내 배변에 봉투를 던져 수거하면 1장을 차감한다. 예산 부족·기간 종료·저장 실패 시 구매하지 않는다.

1. Android 앱을 다시 빌드·설치하고 산책 화면에서 카메라·마이크 권한을 허용한다.
2. 이동하면서 `초코야 앉아`라고 말하고 계속 걸어가도 강아지가 앉은 자리를 유지하는지 확인한다. `가자` 이후 따라오는지 확인한다.
3. `멈춰` 이후 서 있는 자세로 정지하는지, `앉아 → 멈춰 → 가자` 전환과 반복 발화, 이름 없이 말하기, 알 수 없는 발화를 확인한다.
4. 마이크 권한 거부, 음성 끄기·켜기, 다른 화면 이동, 홈 화면 복귀, 화면 잠금 시 중단·재개를 확인한다.
5. 배변 중 요청 및 AR 추적 중단·복귀를 확인한다.
6. 한국어 모델이 있는/없는 기기, 네트워크 연결/해제 상태, 실외 바람 소리에서 인식률·지연·배터리·AR FPS를 확인한다.
