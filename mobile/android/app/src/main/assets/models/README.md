# 강아지 모델

- 원본: [Cartoon Dog - Shiba Inu / billl90](https://www.cgtrader.com/3d-models/animal/mammal/cartoon-dog-shiba-inu)
- 파일: `dog.glb` — 모바일용 메시 4,584 삼각형, 본 57개, 텍스처 1024×1024 내장
- 방향: +Y 위, +Z 정면
- 애니메이션: 이동·회전·대기·생활·점프 등 74개 클립 (`dog.animations.json`에 원본 이름·길이 기록)
- 제자리 애니메이션을 사용하며 월드 이동은 `DogLeader`에서 처리
- 구매 원본과 라이선스는 별도 관리
- 파란 목줄 메시를 적용했으며 기존 74개 애니메이션을 유지한다. `LeashAttachment`는 뒷목의 목줄 표면에 놓인 `neck` 뼈의 자식 노드다.
- AR 산책의 끈은 이 노드에서 화면 하단 중앙으로 이어지는 3D 곡선이다. 목 애니메이션·이동·회전을 따라가며, 손 쪽 끝은 카메라 앞 35cm의 화면 하단 중앙에 고정한다. 거리에 따라 처짐과 장력을 조절한다.
- 강아지가 사용자를 향하면 양옆 목줄 부착점 중 화면 왼쪽 지점을 선택해 끈이 얼굴을 통과하지 않게 한다. 측면·후면에서는 다시 뒷목 지점을 사용한다.
- 목줄의 몸 관통을 줄이기 위해 몸통·목·머리를 애니메이션 뼈에 연결된 캡슐로 근사한다. 목 표면 바깥 4.5cm의 가이드 지점에서 출발하고 줄 구간 전체의 충돌을 검사한다. 충돌 시 제한된 후보 지점 그래프에서 우회 경로를 찾고, 각 모서리를 유지한 24개 구간으로 그린다. 기존 우회 경로가 유효하면 유지하며, 원래 곡선이 8프레임 연속 열렸을 때 복귀한다. 손 쪽 끝점은 계속 화면 하단 중앙에 고정된다.
- 끝점이 몸 안에 있거나 우회 후보에서 경로를 찾지 못하면 해당 프레임의 끈은 숨긴다. 이때 목줄 터치도 비활성화하며 거리 복귀 계산은 두 끝점 사이 거리로 대체한다. 캡슐은 메시의 근사치이므로 실제 기기의 걷기·회전·대기 자세에서 반경 조정이 필요할 수 있다.
- 끈을 짧게 누르면 기존 앞서 걷기보다 호출을 우선하며 초기 배치처럼 사용자의 시선 방향 약 1m 앞에 도달해 사용자를 바라본다. 50cm 접근 조건은 사용하지 않는다. 호출 후에는 앞쪽 위치를 유지하고, 수동 재배치 시 기본 산책 동작으로 돌아간다.
- 실제 끈 길이 또는 수평 거리가 2m 이상이면 자동 복귀한다. 자동 복귀와 터치 호출은 벽·길 판정·높이 차·분석 결과 대기/만료/실패를 무시하고 직진한다. 마지막으로 확인한 바닥 높이를 유지한다. 일반 산책에는 기존 벽·바닥 검사를 적용하며, AR 추적이 끊긴 동안은 복귀도 정지한다.
- 수정 GLB 적용 및 부착점 재생성: `node mobile/scripts/apply-dog-collar.cjs <수정된-목줄-모델.glb>`

## 모의입양 방

- 선택 결과의 `petId`를 `RoomPetView`까지 전달한다. 현재는 모든 품종에 같은 시바견 모델을 임시 사용한다.
- AR 세션 없이 투명한 일반 SceneView에 모델 한 개를 표시하며 약 30fps로 제한한다.
- 배경의 베드 좌표를 기준으로 배치하고, 카메라와 모델 위치를 고정한다. 기본 자세는 정면을 보는 `SitIdle`이다.
- 모델 표시 후 10초가 지나면 `SitEnd → LieStart → LieIdle`로 전환하고 몸을 25도 사선으로 돌린다.
- 18~35초의 임의 간격으로 `LieEnd → ScratchEar → LieStart → LieIdle`을 한 번 재생한다.
- 화면 포커스 이탈 또는 앱 백그라운드 진입 시 뷰와 렌더링 자원을 해제한다. 재진입하면 앉은 자세와 체류 시간을 새로 시작한다.
- AR 산책에서 돌아올 때에는 모델 로딩 완료 후 오른쪽 아래에서 3초 동안 `Walk`로 베드까지 이동한다. 이동은 Animated의 네이티브 드라이버로 처리하며 도착 후 `SitStart → SitIdle`을 재생한다. 휴식까지의 10초는 앉기 완료 후부터 계산한다.
- 품종별 모델·크기 연결, iOS 렌더러, 실제 기기에서의 배치·발열·메모리 검증은 별도 작업이다.

## 재변환

Blender 4.5 LTS에서 프로젝트 루트 기준으로 실행합니다.

```powershell
blender --background --factory-startup --python-exit-code 1 --python mobile/scripts/convert-dog.py -- "<구매 파일 폴더>" "mobile/android/app/src/main/assets/models/dog.glb"
```

모바일 FBX의 메시·스킨을 원본 BLEND의 애니메이션 뼈대에 연결하고,
텍스처 및 베이크한 애니메이션을 하나의 GLB에 포함합니다.

## 재생 규칙

- 정지 3초: 여러 대기 자세 또는 귀 긁기 중 하나를 한 번 재생
- 정지 10초: 웅크리기 또는 땅파기를 시작 → 반복 → 종료 순서로 한 번 재생
- 이동 재개: 정지 동작을 중단하고 이동 애니메이션으로 복귀
- 몸의 방향에 대한 실제 이동 방향과 속도에 따라 전진·후진·옆걸음·대각선·속보·달리기 선택
- AR 산책의 수동 `동작` 메뉴는 사용하지 않으며 대기 동작은 자동 재생
- 클립 사이에는 0.15초 블렌딩 적용. 정지 동작을 이동 중 자막으로 표시하지 않음
- 인식된 수직 벽은 진행 방향을 적게 바꾸는 경로부터 확인하고, 벽을 따라 좌우로 우회
- 우회 중 몸은 진행 방향을 유지하고 옆걸음 사용. 실제 다음 걸음의 바닥과 벽 충돌은 계속 검사
- 좌우 진로가 모두 막히거나 바닥을 확인할 수 없으면 정지
