# AR 산책의 깊이 판정

- 지원 기기에서는 ARCore `AUTOMATIC` Depth를 활성화한다. 화면 진단에 지원·준비·사용 상태를 표시한다.
- 깊이 영상은 5Hz, 최대 약 12,000개 점으로 읽고 즉시 닫는다. texture intrinsics와 카메라 pose로 실제 공간에 투영한다.
- 15cm 셀에서 바닥 기준 ±8cm의 점 3개 이상이면 바닥, 12~85cm 위의 점 3개 이상 또는 12cm 이상 낮은 점 3개 이상이면 장애물이다. 장애물 판정을 먼저 적용한다.
- 관측은 0.6초 뒤 만료한다. 같은 원본 timestamp의 재투영은 새 관측으로 누적하거나 수명을 연장하지 않는다.
- ARCore 평면으로 바닥 높이를 얻고 깊이로 통행을 판단한다. 깊이 관측이 없는 영역과 미지원 기기에서는 기존 SegFormer 판정을 사용한다. 깊이 0 또는 누락은 통행 가능으로 처리하지 않는다.
- 실제 사용자가 지나간 경로가 최우선이다. 일반 산책은 장애물 확인 후 우회하고 경로가 없으면 정지한다. 2m 강제 복귀와 목줄 호출은 장애물을 무시한다.
- 초록·빨강·노랑의 30% 진단 표시에 같은 깊이 판정을 사용한다.

단위 테스트는 영상의 행/픽셀 stride, little-endian, 실제 공간 변환, 만료, 고립 점 제외, 장애물 우선 및 낙차를 검사한다. 실제 기기를 움직이며 보는 바닥·가구·벽의 판정 품질과 프레임 속도는 별도 현장 확인이 필요하다. 이 단계에서는 SegFormer 모델 가중치를 교체하지 않는다.
