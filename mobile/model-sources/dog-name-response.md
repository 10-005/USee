# 이름 호출 반응

대상: `android/app/src/main/assets/models/dog.glb` (현재 AR 산책에서 사용하는 공통 강아지 모델).

GLB JSON의 노드 계층과 skin.joints를 직접 확인했다.

| 역할 | 노드 | 인덱스 | 연결 |
| --- | --- | --- | --- |
| 목 | neck | 17 | Spine_05 → neck → head |
| 머리 | head | 16 | neck의 자식, 얼굴·귀·코 포함 |
| 시선 기준 | nose | 5 | head의 자식 |
| 꼬리 | Tail_01~05 | 38, 37, 36, 35, 34 | Spine_base → Tail_01 → … → Tail_05 |

위 노드는 모두 skin.joints에 포함되어 있다. 별도 고개/꼬리 애니메이션 클립은 없으므로 기본 애니메이션 위에 본 회전 오프셋을 합성한다. 모델 파일 자체는 변경하지 않는다.

- 저장한 이름, 이름+야/아를 단독으로 부르면 3초 동안 위치·몸통 방향을 고정한다.
- 매 프레임 기본 애니메이션과 크로스페이드 적용 후 목·머리를 카메라로 향하게 한다. 수평 회전은 목 67%·머리 33%로 나누고, 상하 회전은 총 ±25도로 제한한다.
- 0.25초 동안 부드럽게 들어가고 마지막 0.25초에 원래 자세로 복귀한다. Tail_01에 처음 2초간 좌우 최대 20도 회전을 적용한다.
- 본의 위치·스케일과 몸통·다리 본은 유지한다. 다음 프레임에 원본 본 변환을 복원한 뒤 다시 애니메이션을 샘플링하여 오프셋 누적을 방지한다. 최종 변환 후 스킨 행렬과 목줄 위치를 갱신한다.
- 기존 앉기·정지는 호출 후에도 유지한다. 일반 산책 중이었다면 3초 후 이동을 재개한다. 행동 명령이 오면 호출 반응을 취소하고 해당 명령을 실행한다. 추적 중단·진행 중인 배변에는 호출 반응을 수행하지 않는다.

실기기 확인: 선택 → 이름 설정 → 예산 → 방 → 산책의 저장 이름 전달, 이름 단독/호격과 이름+명령 구분, 앞·옆·뒤에서 호출 시 목과 머리 회전, 3초 정지·2초 꼬리 흔들기, 앉기·정지 유지, 카메라 추적 중단 후 복원을 확인한다. 카메라 정후방에서의 큰 목 회전은 기기에서 모델 변형을 확인해야 한다.
