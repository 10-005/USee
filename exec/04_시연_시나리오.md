# USee 시연 시나리오

기준일: 2026-11-18. 전체 약 4분(파트 1 약 1분 30초, 파트 2 약 2분 40초).

## 1. 시연 구성

시연은 Android 휴대폰 2대로 한다. 두 폰의 화면을 노트북(OBS)으로 받아 빔프로젝터에 송출한다.

| 폰 | 담당 | 시연 속 역할 | 로그인 계정 | 화면 연결 |
|---|---|---|---|---|
| 폰 1 | 이한준(시연자) | 후추 보호자, 모의 입양 체험자 | 후추가 "내 동물"에 등록된 계정 | scrcpy 무선 |
| 폰 2 | 김상현(오퍼레이터) | 길에서 고양이를 발견한 시민 | 다른 일반 회원 계정 | scrcpy USB |

송출 장면은 4개다: 발표 자료, 폰 1 단독, 2분할(왼쪽 폰 1, 오른쪽 폰 2), 영상.

## 2. 사전 준비

| 항목 | 확인 내용 |
|---|---|
| 서버 | 두 폰에서 앱 홈 화면이 정상 로딩되는지 확인 |
| 폰 1 | USee 로그인, "내 동물" 목록에 고양이 **후추** 등록, USee 알림 허용, 다른 앱 알림 끔 |
| 폰 2 | USee 로그인(폰 1과 다른 계정), 카메라·위치 권한 허용, 제보에 쓸 고양이 사진 촬영 준비 |
| 공통 | 화면 자동 꺼짐 10분, 네트워크 연결(폰 1은 노트북 핫스팟) |
| 모의 입양 | 폰 1 계정에 진행 중인 모의 입양이 없는 상태(새로 시작할 수 있어야 한다) |
| AR | 폰 1이 ARCore 지원 기기인지, 마이크 권한을 허용했는지 확인. 바닥이 보이는 공간 확보 |

## 3. 파트 1. 실종 신고와 AI 매칭 (약 1분 30초)

보호자가 실종 신고를 올리고, 시민이 닮은 고양이를 제보하면, AI 이미지 매칭으로 보호자에게 알림이 가는 흐름이다.

| # | 폰 | 화면 | 조작(누르는 위치) | 화면에 나타나는 결과 | 발표 멘트 |
|---|---|---|---|---|---|
| 1 | 폰 1 | 홈 | **+ 버튼** → **잃어버렸어요** | 실종 신고 작성 화면 | "지금부터 시연을 통해 보여드리겠습니다." |
| 2 | 폰 1 | 실종 신고 1단계(동물 선택) | 내 동물 목록에서 **후추** 선택 → 아래로 스크롤 → **다음** | 후추의 사진·품종·특징이 자동으로 채워짐 | "보호자는 내 동물 목록에서 후추를 선택합니다." |
| 3 | 폰 1 | 실종 신고 2단계(일시·장소) | **실종일** 선택 → **실종 장소** 검색창에 "구미시청" 입력 후 선택 → **다음** → **게시글 등록** | 실종 게시글 등록 완료, 상세 화면 표시 | "이후 실종 일자를 입력하고 실종 장소를..." |
| 4 | 폰 1 | 찾아요 탭(선택) | 하단 **찾아요** 탭 → 목록 스크롤 | 실종·제보 게시글 목록 | (시간이 부족하면 생략) |
| 5 | 폰 2 | 홈 → 제보 작성 | **+ 버튼** → **목격했어요** → 고양이 사진 촬영 → 사진 등록 | **AI 품종 추천** 결과(종·품종 후보)가 표시됨 | "지금 마침 한 시민이 후추와 닮은 고양이를 발견한 것 같습니다." |
| 6 | 폰 2 | 제보 작성(일시·장소) | 추천 품종 확인 → **발견 날짜** 선택 → **발견 장소** 선택 → **등록** | 제보 게시글 등록 완료 | "발견 날짜와 장소를 추가하여 제보 게시글을 등록하겠습니다." |
| 7 | 폰 1 | (대기) | 조작 없음 | 화면 위에 **AI 매칭 푸시 알림** 도착 | "후추 보호자에게 알림이 왔습니다!" |
| 8 | 폰 1 | 알림 | **푸시 알림을 터치** | 알림에 연결된 **제보 게시글 상세**로 이동 | "방금 온 알림처럼 USee는 AI 이미지 매칭을 통해..." |
| 9 | 폰 1 | 제보 상세 | 사진 → 발견 위치(지도) → 특징 순으로 스크롤 | 제보 사진, 발견 위치, 특징 확인 | "알림에 연결된 제보 게시글에서..." |

내부 동작(5~7번): 제보가 등록되면 core-api가 `MatchRequested` 이벤트를 발행한다. match-worker가 사진을 벡터로 바꿔 실종 게시글과 유사도를 비교하고, 결과(`AiMatchFound`)를 돌려준다. core-api가 알림을 만들고 notification이 FCM으로 푸시를 보낸다. 알림 도착까지 수 초가 걸린다.

송출 장면 전환:

| 시점 | 송출 장면 |
|---|---|
| 1번 시작 | 발표 자료 → 폰 1 단독 |
| 5번 멘트 직전(폰 2를 들기 전) | 폰 1 단독 → 2분할 |
| 7번에서 폰 1에 알림이 보인 뒤 | 2분할 → 폰 1 단독 |

## 4. 파트 2. 모의 입양 시뮬레이션 (약 2분 40초)

처음부터 끝까지 폰 1 화면만 송출한다.

| # | 화면 | 조작(누르는 위치) | 화면에 나타나는 결과 | 발표 멘트 |
|---|---|---|---|---|
| 1 | 입양 탭 | 하단 **입양** 탭 → 보호 동물 목록 스크롤 → **시바견** 카드 선택 | 보호 동물 상세(사진, 보호소, 특징) | "이번에는 새로운 가족을 만날 준비를 해보겠습니다." |
| 2 | 보호 동물 상세 → 모의 입양 | **모의 입양** 버튼 → **모의입양 시작하기** | 모의 입양 시작 화면 | "이 친구를 가족으로 맞이하고 싶다면," |
| 3 | 모의 입양 설정 | **체험 동물** 선택 → 이름 입력란에 **감자** 입력 → **예산** 설정 → 다음 | 감자와의 7일 체험 시작 | "먼저 함께할 동물을 선택하고, 이름을 지어주겠습니다." |
| 4 | 상점 | **상점** → **밥그릇**, **영양사료**, **배변봉투**, **리드줄** 담기 → **장바구니** → **구매** | 예산에서 금액 차감, 보유 용품에 추가 | "감자와의 생활에 필요한 용품부터 준비하겠습니다." |
| 5 | 돌봄 | 돌봄 화면 → **밥 주기** → **물 주기** → 화면의 **강아지를 터치** | 밥·물을 준 내용이 반영되고 강아지 상태가 표시됨 | "이제 구매한 용품으로 감자를 돌봐주겠습니다." |
| 6 | AR 산책 | **산책** → 카메라로 바닥을 비춤 → 바닥을 터치해 **동물 배치** → 폰을 들고 걷기 | 실제 바닥 위에 강아지가 나타나 따라 걸음 | "이번에는 감자와 산책을 나가보겠습니다." |
| 7 | AR 산책(음성) | 폰에 대고 **"감자야"** → 이어서 **"감자 돌아"** | "감자야"에 뒤돌아봄 → "감자 돌아"에 제자리에서 돎 | "감자를 한번 불러볼까요?" |
| 8 | AR 산책(돌발 상황) | 배변 이벤트 발생 → **배변봉투 던지기**(1회 실패 후 다시 던져 성공) | 배변 처리 완료 | "돌발 상황이 발생했습니다!" |
| 9 | 산책 종료 | 산책을 끝냄 | 시연 종료 | "감자와의 산책을 끝내며 시연을 마무리하겠습니다." |

- 9번 멘트와 함께 송출을 발표 자료로 돌린다.
- 음성 명령은 폰의 마이크가 직접 인식한다(기기 내 음성 인식). 주변이 시끄러우면 폰을 입 가까이에 댄다.
- 7일 체험이 끝나면 돌봄·지출 기록으로 리포트가 만들어지고, 보호소는 입양 신청을 검토할 때 이 리포트를 볼 수 있다. 시연에서는 다루지 않는다.

## 5. 문제 발생 시 대응

관객 화면을 먼저 안전한 장면(발표 자료)으로 돌린 뒤 고친다.

| 상황 | 바로 할 일 | 복구 |
|---|---|---|
| 폰 1 화면이 멈춤 | 발표 자료로 송출 전환, 발표자가 말로 이어감 | 폰 1을 USB로 연결해 화면 연결을 다시 실행 |
| 폰 2 화면이 멈춤 | 폰 1 단독으로 송출 | USB를 다시 꽂고 화면 연결을 다시 실행 |
| AI 매칭 알림이 오지 않음 | 2분할을 유지하고 몇 초 기다림 | 폰 1의 앱 내 알림 목록에서 같은 제보를 연다 |
| AR에서 바닥을 인식하지 못함 | 폰을 천천히 좌우로 움직여 바닥을 다시 비춤 | 밝은 곳, 무늬가 있는 바닥으로 이동 |
| 음성 인식이 되지 않음 | 한 번 더 또렷하게 말함 | 넘어가고 8번(돌발 상황)으로 진행 |
| 사진 업로드 실패 | 네트워크 확인 후 다시 등록 | 미리 찍어 둔 갤러리 사진으로 등록 |

## 6. 부록: 송출 조작(오퍼레이터용)

| 동작 | 단축키 |
|---|---|
| 발표 자료를 미리보기에 올리기 | Ctrl + 1 |
| 폰 1 단독을 미리보기에 올리기 | Ctrl + 2 |
| 2분할을 미리보기에 올리기 | Ctrl + 3 |
| 영상을 미리보기에 올리기 | Ctrl + 4 |
| 송출(미리보기 → 프로그램) | Ctrl + ` |

- 장면을 전환하자마자 다음 장면을 미리보기에 올려 둔다.
- 키보드 포커스는 PowerPoint 발표자 보기에 둔다. 슬라이드는 방향키로, 장면은 단축키로만 조작한다.
- 준비 순서: 노트북 전원·알림 끄기 → 빔프로젝터 확장 모드 → OBS 전체 화면 프로젝터 → 폰 1·폰 2 화면 연결 → 장면 4개 확인 → 발표 자료를 송출 상태로 둔다.
