# USee 환경 변수 전체 목록

기준일: 2026-11-18. 값은 적지 않는다. "비밀" 열이 O인 항목은 SealedSecret, GitLab CI 변수, 로컬 `.env`에만 둔다.

서버 값의 출처:
- **env**: `infra/services/<서비스>/base/deployment.yaml`의 `env`(비밀이 아닌 값)
- **Secret 이름**: `infra/platform/secrets/`의 SealedSecret

## 1. 백엔드 공통 (서비스 4개)

| 변수 | 용도 | 기본값(로컬) | 서버 값 출처 | 비밀 |
|---|---|---|---|---|
| `SPRING_PROFILES_ACTIVE` | 프로파일 | `local` | env: `dev` | |
| `SPRING_DATASOURCE_URL` | DB 접속 URL | (로컬은 `DB_HOST`·`DB_PORT`·`DB_NAME`으로 조합) | env: `jdbc:postgresql://postgres.data.svc.cluster.local:5432/animal?currentSchema=<스키마>` | |
| `SPRING_DATASOURCE_USERNAME` | DB 계정 | (로컬은 `DB_USERNAME`) | env: 서비스별 계정(`core_app` 등) | |
| `DB_PASSWORD` | DB 비밀번호 | 없음 | `<서비스>-secrets` | O |
| `DB_HOST` / `DB_PORT` / `DB_NAME` / `DB_USERNAME` | 로컬 DB 접속 | `localhost` / `5432` / `animal` / `.env` | 서버에서는 쓰지 않음 | |
| `SPRING_DATA_REDIS_HOST` / `SPRING_DATA_REDIS_PORT` | Redis 접속 | (로컬은 `REDIS_HOST`·`REDIS_PORT`) | env: `redis.data.svc.cluster.local` / `6379` | |
| `REDIS_HOST` / `REDIS_PORT` | 로컬 Redis 접속 | `localhost` / `6379` | 서버에서는 쓰지 않음 | |
| `REDIS_PASSWORD` | Redis 비밀번호 | 없음 | `<서비스>-secrets` | O |
| `RABBITMQ_HOST` / `RABBITMQ_PORT` | RabbitMQ 접속 | `localhost` / `5672` | env: `rabbitmq.data.svc.cluster.local` / `5672` | |
| `RABBITMQ_USERNAME` / `RABBITMQ_PASSWORD` | RabbitMQ 계정 | `.env` | `rabbitmq-app` | O |
| `EVENTS_TRANSPORT` | 이벤트 전달 방식. `log`는 로그만, `rabbit`은 RabbitMQ 발행 | `log` | env: `rabbit` | |
| `JWT_PUBLIC_KEY` | JWT 검증 키(RS256, Base64 X.509 DER). 필수 | 없음 | `<서비스>-secrets` | O |
| `CORS_ALLOWED_ORIGINS` | CORS 허용 출처(쉼표 구분) | `http://localhost:5173,http://127.0.0.1:5173` | env: 로컬 2개 + `https://s15p31d106-develop-web.vercel.app` | |
| `HOSTNAME` | JSON 로그의 파드 이름 | `unknown` | 쿠버네티스가 자동 설정 | |

서비스별 DB 계정·스키마: core-api `core_app`/`core`, chat `chat_app`/`core`, notification `notification_app`/`core`, simulation `simulation_app`/`simulation`.
