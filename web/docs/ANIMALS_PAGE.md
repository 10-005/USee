상태·기간·축종·성별·입양가능여부·중성화여부는 AND 조건으로 적용합니다.
필터와 정렬은 URL 검색 매개변수에 저장되어 새로고침 및 뒤로 가기 시 유지됩니다.
잘못된 필터 값은 전체, 잘못된 정렬 값은 최신순으로 처리합니다.
기간은 예시 기준일 2026-11-01을 포함한 최근 7일/30일/90일의 **등록일** 기준입니다.
원본에 구체적인 기간 옵션이 없어 예시 동작으로 정했으며 API 연동 시 실제 기준을 확정해야 합니다.
필터 초기화는 모든 필터와 정렬을 초기값으로 돌립니다.

카드 선택은 `/animals/:id` 상세 화면을 엽니다. `/animals/new`에서 등록하고
`/animals/:id/edit`에서 사진·기본 정보·공고 기간·보호 상태를 수정할 수 있습니다.
입양신청(`/adoptions`)과 구조일지(`/rescues`)는 필터·페이지 이동·상세 화면을 제공합니다.
입양 심사, 구조 접수(`/rescues/new`)와 상태 저장, 발견 신고(`/reports`)에서 접수하기,
마이페이지(`/profile`) 정보 수정이 예시 데이터로 동작합니다.
로그인(`/login`)은 `demo` / `demo`로 홈으로 이동하는 예시이며 실제 인증이 아닙니다.
변경사항은 Zustand 메모리에만 반영되며 새로고침하면 초기화됩니다.
채팅 목록의 열기·닫기·안 읽음 필터·대화 선택은 동작하며 송수신은 포함하지 않습니다.
실제 인증·채팅 송수신·서버 저장은 API 연결 단계에서 구현해야 합니다.

로딩·오류·페이지 처리도 함께 연결합니다. 현재는 24개를 모두 표시합니다.
