채팅 메시지 송수신과 실제 페이지별 API 연동은 포함하지 않습니다.

## 모달·테이블

`/dev/ui`에서 작성 취소 모달, 입양신청 예시 테이블, 빈 결과와 페이지 이동을 확인합니다.

| 컴포넌트             | Figma 원본                 | 책임                                                       |
| -------------------- | -------------------------- | ---------------------------------------------------------- |
| Modal / ConfirmModal | 1134:56032 내부 1118:53340 | 제목·설명·본문·액션 슬롯, 작성 취소 확인                   |
| DataTable            | 1112:26702                 | 열 정의·행 데이터·고유 키, 헤더와 셀, 빈 결과, 가로 스크롤 |
| Pagination           | 1112:26702                 | 이전·다음 및 최대 5개의 페이지 번호, 경계 비활성화         |

Modal은 `open`과 `onClose`로 제어합니다. `showModal()`로 배경을 비활성화하고,
Tab 순환, Escape 닫기 요청, 스크롤 잠금 및 열기 전 포커스 복귀를 제공합니다.
확인 모달은 배경 클릭으로 닫히지 않습니다. `onConfirm`에서 실제 처리와 닫기 여부를 결정합니다.
중첩 모달은 사용하지 않습니다. 작성 취소 버튼의 회색은 Figma 원본 색상이며 비활성 상태가 아닙니다.

DataTable은 `TableColumn<T>[]`의 `id`, `header`, `render(row)`, 선택적 `width`와
`rows`, `rowKey`, `caption`을 받습니다. 상태·사진·액션은 render에서 기존 컴포넌트와 조합합니다.
테이블 최소 너비는 원본의 1040px이며 좁은 화면에서는 테이블 영역만 가로 스크롤됩니다.
Pagination의 `page`는 1부터 시작합니다. 데이터 조회·정렬·필터·페이지별 행 분할은 호출 화면 책임입니다.
미리보기는 기존 예시 사진과 가상 신청자를 사용하며 운영 API를 호출하지 않습니다.
원본 테이블 구분선 SVG는 로컬 에셋으로 저장했습니다. 모달·테이블도 공통 Pretendard 글꼴을 사용합니다.
