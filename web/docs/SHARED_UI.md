메뉴는 ReactNode 슬롯이므로 사용하는 화면에서 Link/NavLink와 활성 상태를 전달합니다.
채팅 데이터·선택·열림 상태, 목록 조회·정렬, 폼 저장은 사용하는 화면이 관리합니다.
ImageUpload는 File 배열만 전달하며 업로드 API를 호출하지 않습니다. 서버에서도 파일 검증이 필요합니다.
선택 상태·호버·모바일 배치는 접근성 및 반응형 동작을 위한 구현 보완입니다.

원본 로고·채팅 마스코트·아이콘은 `src/shared/assets/figma`에 저장했습니다.
동물 사진·프로필 이미지는 미리보기용 원본이며 컴포넌트에서는 URL props로 받습니다.
채팅 메시지 송수신, 실제 페이지별 API 연동, 테이블·모달은 포함하지 않습니다.
